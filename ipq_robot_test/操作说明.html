1烧录步骤

  1. Arduino IDE 安装 esp32 by Espressif Systems 开发板包（开发板管理器搜索 esp32，选 Espressif 那个）。
  2. 工具 → 开发板 选 ESP32 Dev Module，其余选项保持默认。
  3. USB 线连接 ESP32，工具 → 端口 选对应 COM 口。
  4. 点击「上传」。
烧录卡在 Connecting 时：按住板上 BOOT 键再点上传，开始写出时松开；若仍失败，拔掉 microSD 模块再烧（GPIO2 是启动脚），烧完再插回。
不需要安装任何第三方库——程序只用了核心自带的 Wire / SPI / SD，INA226 和 IMU 都是程序内直接寄存器读写。串口监视器波特率设 115200。

上电默认电机为滑行断电状态，发 'g' 或 'w' 开始测试。

之后每 100ms 打印一行遥测数据（10Hz）。

检查点：
· I²C 扫描必须出现 0x40（INA226）；IMU 支持 MPU6050（0x68/0x69）和 LSM6 系（0x6A/0x6B）以及身份码异常的兼容芯片，自动识别；
· SD 行显示文件名说明记录正常；显示"初始化失败"不影响其它功能；
· 上电后电机不转是正常的（安全设计，滑行断电），必须发命令才动。

3串口命令（串口监视器输入单个字符发送）

命令作用
w前进（当前速度）
s后退
a原地左转（左轮退、右轮进）

上电默认速度 30%（对应接线清单"PWM 30% 低速试转"的要求）。

4遥测数据怎么读

串口每行格式：

[  12.3s] encL +1234 (+33)  encR  -567 (-12)  rpm L  -12.3 R  -5.6 | bat 7.82V  cur 0.312A  pow 2.44W | acc +0.02 -0.99 +0.05 g  gyr   1.2  -0.5   3.4 dps  28.5C
字段含义正常参考值
encL/encR左/右轮累计计数（括号内是本周期增量）前进时增大；每 330 计数 = 轮轴一圈
rpm L/R左/右轮轴转速（转/分），带方向空载 30% 大约 ±100~150
bat电池电压（INA226 母线端）2S 满电 8.4V，<6.4V 该充电
cur电机总电流空转零点几安，顶到 ±0.82 不再涨＝堵转超量程
pow电机功率 = V×I—
acc加速度（单位 g）静止水平放置约 0 0 ±1
gyr角速度（°/s）静止时接近 0
CIMU 芯片温度室温~35°C
SD 卡记录：同样的数据每 100ms 追加一行到 /ipqNNN.csv（文件名自动递增不覆盖，每秒落盘一次）。断电后取卡插电脑，Excel / Python pandas 直接读，列名在 CSV 第一行。

5首次测试推荐流程（安全顺序）

  1. 架空轮子（垫起车体，轮子离地），接好电源。
  2. 上电 → 确认 I²C 扫描出 0x40、IMU 识别成功，遥测正常滚动。
  3. 静止读数体检：acc 第三列 ≈ ±1，gyr ≈ 0，bat ≈ 电池实际电压。
  4. 发 g 跑演示序列，观察：
    • 某个轮子转向不对 → 记下是哪个（见第 6 节方向修正）；
    • 某个轮子 enc 计数一直是 0 → 查该编码器 VCC/GND/A/B 四根线；
    • 前进时某侧计数是负的 → 编码器方向反（第 6 节）。
  5. 都正常后发 w 手动开，用 +/- 逐步提速；结束发 x。
  6. 一切正常后再放下地面，低速直线测试，用 z 清零后走固定距离核对编码器刻度。

6方向反了怎么改（二选一）

改接线（推荐，一劳永逸）：转向反的电机，把 DRV8833 上该电机的两根输出线对调（左 = AO1/AO2，右 = BO1/BO2）；编码器方向反则对调该电机的 A/B 相两根信号线。

改软件（免重新接线）：打开 .ino，改文件开头的宏再重新上传：

#define MOT_L_INVERT 0   // 'w' 前进时左轮反转 → 改 1
#define MOT_R_INVERT 0   // 'w' 前进时右轮反转 → 改 1
#define ENC_L_INVERT 0   // 前进时左编码器计数变负 → 改 1
#define ENC_R_INVERT 0   // 前进时右编码器计数变负 → 改 1

7其它可调参数（文件开头）

#define PWM_FREQ_HZ 20000  // 电机 PWM 频率，DRV8833 上限 250kHz
#define TELE_MS      100    // 遥测/记录周期(ms)
#define R_SHUNT      0.1f   // INA226 采样电阻：看板上粗电阻丝印，R100=0.1(默认)
                           //   R010=0.01Ω → 改 0.01；R001=0.001Ω → 改 0.001
#define ENC_PPR      11     // 编码器每转脉冲（JGB37-520B 出厂 11）
#define GEAR_RATIO   30     // 减速比（电机标签 1:30）
电流读数说明：INA226 分流满量程 ±81.92mV。配常见的 0.1Ω(R100) 分流电阻时，可测电流上限约 ±0.82A——正常运行电流足够，堵转电流会被削顶（读数停在 0.82 附近）。这不影响电压/功率趋势判断；若板子丝印不是 R100，按上表改 R_SHUNT。

8常见问题排查

现象排查
烧录失败 / 卡在 Connecting按住 BOOT 键再点上传；拔掉 microSD 模块（GPIO2）
I²C 扫描一个地址都没有查 21(SDA)/22(SCL) 是否接反；红轨 3.3V / 蓝轨 GND 是否正常
有一个地址、缺另一个缺的器件单独查 4 根线（VCC/GND/SDA/SCL）；扫描出 0x6B 属正常（LSM6 系地址），程序自动识别
电机完全不动、无电流DRV8833 的 STBY 是否接了 3.3V（悬空芯片不工作）；VM 上量电池电压
一侧转一侧不转查不转那侧的 IN1/IN2 两根控制线（23/19 或 18/16）和电机两根动力线
电流读数总是 0电机线必须从 INA226 的 VIN+/VIN− 走（清单线 1/2），接反则读数为负
SD 初始化失败卡是否插反；模块 VCC 电压（有稳压器的板接 5V，直通的接 3.3V）；CS(27)/MISO(2) 接线
数据偶尔跳变电池电压过低，或面包板轨道中段断开（用万用表量红轨首尾通断）
