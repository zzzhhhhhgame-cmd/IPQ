# IPQ 机器人全系统测试程序 · 操作说明

对应程序：`ipq_robot_test.ino`（引脚与 wiring-checklist.html v3.3 逐线对应）
硬件：ESP32 DevKit V1 · DRV8833 · JGB37-520B(1:30)×2 · INA226 · IMU(MPU6050/LSM6DS3 自动识别) · microSD

---

## 1. 烧录步骤

1. Arduino IDE 安装好 **esp32 by Espressif Systems** 开发板包（开发板管理器中搜索 esp32 安装第一个，不是 "Arduino ESP32 Boards"）。
2. **工具 → 开发板** 选 **ESP32 Dev Module**，其余选项保持默认。
3. 用 USB 线连接 ESP32，**工具 → 端口** 选对应 COM 口。
4. 点击「上传」。⚠ 如果卡在 `Connecting........_____`：按住板上的 **BOOT** 键不放，点上传，开始写出时松开；若仍失败，**拔掉 microSD 模块再烧**（GPIO2 是启动脚，SD 卡会干扰进烧录模式），烧完再插回。
5. 打开**串口监视器**，波特率设 **115200**。

**不需要安装任何第三方库**——程序只用了核心自带的 Wire / SPI / SD，INA226 和 MPU6050 都是程序内直接寄存器读写。

---

## 2. 上电/复位后会看到什么

串口按顺序输出：

```
===== IPQ 机器人全系统测试 =====
I2C 扫描: 0x40 0x6B
  INA226 (0x40): 在线
  INA226 配置: 成功(16次平均)
  [IMU诊断] 0x6B: WHO_AM_I(0x0F)=0x69
  [IMU诊断] 0x6B 按 LSM6 寄存器试探成功(CTRL回读一致)，静止合加速度 1.02 g ≈1g → 按兼容芯片启用
  IMU: LSM6 系 (0x6B) 初始化成功
SD: 日志写入 /ipq000.csv
编码器: 11 脉冲/圈 × 1:30 = 每圈轮轴 330 个计数(A相上升沿)
===== 命令（串口发送单个字符）===== ...
上电默认电机为滑行断电状态，发 'g' 或 'w' 开始测试。
```

之后每 100ms 打印一行遥测数据（10Hz）。

**检查点：**
- I²C 扫描必须出现 `0x40`（INA226）。IMU 支持 **MPU6050（0x68/0x69）** 和 **LSM6DS3（0x6A/0x6B）** 两种芯片，程序自动识别，`IMU: ... 初始化成功` 那行会显示识别到的型号（本套实测为 LSM6DS3 @0x6B，属正常）。
- SD 行显示文件名说明记录正常；显示"初始化失败"也不影响其它功能（无卡/接触不良/VCC 电压按清单说明②检查）。
- **上电后电机不转是正常的**（安全设计，滑行断电），必须发命令才动。

## 3. 串口命令（在串口监视器输入单个字符发送）

| 命令 | 作用 |
|------|------|
| `w` | 前进（当前速度） |
| `s` | 后退 |
| `a` | 原地左转（左轮退、右轮进） |
| `d` | 原地右转 |
| `x` | 刹车（能耗制动，立即停） |
| `c` | 滑行（断电，惯性滑到停） |
| `+` | 速度 +10%（上限 100%） |
| `-` | 速度 −10% |
| `0`~`9` | 直接设定速度 0%~90%（如 `3` = 30%） |
| `g` | 演示序列：前进 2s → 刹车 0.8s → 后退 2s → 刹车 |
| `v8.06` | 设置电池电压替代值（按万用表实测输入；功率按它计算，换新 INA226 模块后自动用实测） |
| `tl1.05` / `tr0.94` | 左/右轮 PWM 微调（校正差速，0.80~1.20；单独的 `t` 仍是遥测开关） |
| `z` | 编码器计数清零 |
| `p` | 立即打印一帧数据（不影响周期遥测） |
| `t` | 开/关周期遥测打印（SD 记录不受影响，一直在写） |
| `h` | 显示帮助 |

上电默认速度 **30%**（对应接线清单"PWM 30% 低速试转"的要求）。

## 4. 遥测数据怎么读

串口每行格式：

```
[  12.3s] encL +1234 (+33)  encR  -567 (-12)  rpm L  -12.3 R  -5.6 | bat 7.82V  cur 0.312A  pow 2.44W | acc +0.02 -0.99 +0.05 g  gyr   1.2  -0.5   3.4 dps  28.5C
```

| 字段 | 含义 | 正常参考值 |
|------|------|-----------|
| `encL/encR` | 左/右轮累计计数（括号内是本周期增量） | 前进时增大；每 330 计数 = 轮轴一圈 |
| `rpm L/R` | 左/右轮轴转速（转/分），带方向 | 空载 30% 大约 ±100~150 |
| `bat` | 电池电压（INA226 母线端） | 2S 满电 8.4V，<6.4V 该充电 |
| `cur` | 电机总电流 | 空转零点几安，顶到 ±0.82 不再涨＝堵转超量程 |
| `pow` | 电机功率 = V×I | — |
| `acc` | 加速度（单位 g） | 静止水平放置约 `0 0 ±1` |
| `gyr` | 角速度（°/s） | 静止时接近 0 |
| `C` | IMU 芯片温度 | 室温~35°C |

**SD 卡记录**：同样的数据每 100ms 追加一行到 `/ipqNNN.csv`（文件名自动递增，不会覆盖旧数据，每秒落盘一次）。断电后取卡插电脑，可直接用 Excel / Python pandas 读取，列名在 CSV 第一行。

## 5. 首次测试推荐流程（安全顺序）

1. **架空轮子**（垫起车体，轮子离地），接好电源。
2. 上电 → 确认 I²C 扫描出 0x40、0x68，遥测正常滚动。
3. 静止读数体检：`acc` 第三列 ≈ ±1，`gyr` ≈ 0，`bat` ≈ 电池实际电压。
4. 发 `g` 跑演示序列，观察：
   - 某个轮子转向不对 → 记下是哪个（详见第 6 节方向修正）；
   - 某个轮子 `enc` 计数一直是 0 → 查该编码器 VCC/GND/A/B 四根线；
   - 前进时某侧计数是负的 → 编码器方向反（第 6 节）。
5. 都正常后发 `w` 手动开，用 `+`/`-` 逐步提速；结束发 `x`。
6. 一切正常后再放下地面，低速直线测试，用 `z` 清零后走固定距离核对编码器刻度。

## 6. 方向反了怎么改（二选一）

**改接线（推荐，一劳永逸）**：转向反的电机，把 DRV8833 上该电机的两根输出线对调（左电机 = AO1/AO2，右电机 = BO1/BO2）；编码器方向反则对调该电机的 A/B 相两根信号线。

**改软件（免重新接线）**：打开 `.ino`，改文件开头的宏再重新上传：

```cpp
#define MOT_L_INVERT 0   // 'w' 前进时左轮反转 → 改 1
#define MOT_R_INVERT 0   // 'w' 前进时右轮反转 → 改 1
#define ENC_L_INVERT 0   // 前进时左编码器计数变负 → 改 1
#define ENC_R_INVERT 0   // 前进时右编码器计数变负 → 改 1
```

## 7. 其它可调参数（文件开头）

```cpp
#define PWM_FREQ_HZ 20000  // 电机 PWM 频率，DRV8833 上限 250kHz
#define TELE_MS      100    // 遥测/记录周期(ms)
#define R_SHUNT      0.1f   // INA226 采样电阻：看板上粗电阻丝印，R100=0.1(默认)
                           //   R010=0.01Ω → 改 0.01；R001=0.001Ω → 改 0.001
#define ENC_PPR      11     // 编码器每转脉冲（JGB37-520B 出厂 11）
#define GEAR_RATIO   30     // 减速比（电机标签 1:30）
```

⚠ 电流读数说明：INA226 分流满量程 ±81.92mV。配常见的 0.1Ω(R100) 分流电阻时，**可测电流上限约 ±0.82A**——正常运行电流足够，堵转电流会被削顶（读数停在 0.82 附近）。这不影响电压/功率趋势判断；若你的板子丝印不是 R100，按上表改 `R_SHUNT`。

## 8. 常见问题排查

| 现象 | 排查 |
|------|------|
| 烧录失败 / 卡在 Connecting | 按住 BOOT 键再点上传；拔掉 microSD 模块（GPIO2） |
| I²C 扫描一个地址都没有 | 查 21(SDA)/22(SCL) 是否接反；红轨 3.3V / 蓝轨 GND 是否正常 |
| 有一个地址、缺另一个 | 缺的器件单独查 4 根线（VCC/GND/SDA/SCL）；扫描出 `0x6B` 属正常（LSM6DS3 的地址），程序会自动识别 |
| 电机完全不动、无电流 | DRV8833 的 **STBY 是否接了 3.3V**（清单线 10，悬空芯片不工作）；VM 上量电池电压 |
| 一侧转一侧不转 | 查不转那侧的 IN1/IN2 两根控制线（23/19 或 18/16）和电机两根动力线 |
| 电流读数总是 0 | 电机线必须从 INA226 的 VIN+/VIN− 走（清单线 1/2），接反则读数为负 |
| SD 初始化失败 | 卡是否插反；模块 VCC 电压（清单说明②：有稳压器的板接 5V，直通的接 3.3V）；GPIO2 接触 |
| 数据偶尔跳变 | 电池电压过低或面包板轨道中段断开（清单说明③，用万用表量红轨首尾通断） |
