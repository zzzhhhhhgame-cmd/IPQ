# IPQ 小车模块载板（面包板 → PCB）

把 `wiring v3.3` 的 **42 根杜邦线变成一块 PCB**。板上提供 ESP32 / DRV8833 / GY-521 的排母插座和电池、电机、编码器接线端子；INA226、MP1584、microSD 三个"丝印版本多变"的模块通过标牌插座 + 杜邦线/短线对接（**任意版本都兼容，不会插错**）。固件（`ipq_robot_test` / `ipq_pid_speed`）引脚无需任何改动。

- 板子：**95 × 80 mm，2 层，1.6mm**，底层整板 GND 铺铜（带热焊盘）
- 电气上与面包板版完全一致：逻辑电源在 INA226 之前分支（INA226 只测电机能耗）、STBY 接 3V3、INA226 串联在 电池+ → VM 之间

## 嘉立创下单步骤

1. 打开 [jlc.com](https://www.jlc.com) → PCB 制造 → **上传 PCB 制造文件**，选 `out/IPQ_CARRIER_V1_gerber.zip`。
2. 参数确认（其余默认）：
   - 层数 **2**，板厚 **1.6mm**，数量 **5**（经济板约 ¥2–10 + 运费）
   - 颜色任意（绿色最便宜/最快），表面处理默认"喷锡（有铅）"，阻焊覆盖过孔：是
   - 系统识别的最小线宽/间距应 ≥ 0.4/0.2mm（本板最小值，满足经济板工艺）
3. 预览核对：上传后在线预览应与 `preview_top.png` 一致（顶层丝印 "IPQ-2026 ROBOT CARRIER v1.0"）。

## ⚠ 下单前必做：两个尺寸核对（拿尺子量你手上的模块）

插座位置按以下尺寸设计，若与你手上的模块不符，**先改 `gen_board.py` 顶部常量再重新生成**：

| 模块 | 设计采用尺寸 | 怎么量 |
|---|---|---|
| ESP32 DevKit V1 30P | 两排孔中心距 **22.86mm**（0.9 英寸，行业标准） | 量板上两排焊孔中心距离 |
| DRV8833 (D2-1-2F) | 2 列 × 8 孔、列内间距 2.54、**两列中心距 10.16mm** | 对照模块丝印逐孔核对：左列 NC·AIN2·AIN1·STBY·BIN1·BIN2·NC·GND，右列 VM·NC·GND·AO1·AO2·BO2·BO1·GND |
| GY-521 | 1×8 孔 @2.54 | 通用 |

> 若 DRV8833 实测列距不是 10.16mm（比如 12.7），只需改 `gen_board.py` 中 `DX_R = 62.16` 一行（= 左列 x + 实测列距），重跑生成器即可，布线已按 2.54 网格自适应大部分调整。

## 装配顺序（建议）

1. 焊 C2（瓷片，最矮）→ C1（电解，**长脚为正极朝 VM 一侧**，板上丝印有 + 标记）。
2. 焊全部排母、端子、J9/J P1 跳线座。端子焊缝开口朝板外（插线方向）。
3. 插上 ESP32（USB 朝板上边缘，对照丝印 "USB THIS END"）。
4. **DRV8833 模块先自己焊好 2×8 排针**（模块丝印朝上时：左列对齐载板左列丝印 NC·AIN2·AIN1·STBY·…），再插入排母。
5. GY-521 直接插入 1×8 排母（板上丝印 VCC·GND·SCL·SDA·…）。
6. 三根杜邦线对接 MP1584（**按丝印一一对应**：IN+/IN−/OUT+/OUT−）；四根对接 INA226 逻辑侧（VCC/GND/SDA/SCL）。
7. 动力路径两根粗线（≥20AWG）：
   - `J8 BAT+` 端子同时压接「电池盒红线」+「去 MP1584 的分接线」（与面包板方式 A 相同）
   - `J6 V+IN` → INA226 模块 **VIN+** 端子；INA226 模块 **VIN−** → `J6 V-OUT`
8. microSD 六根杜邦线按丝印对接；JP1 按模块版本把中间焊盘与 3V3 或 5V 焊锡桥接。
9. 电机线接入 J13/J14（M+/M−），编码器线接入 J2/J3（板上丝印 A·B·GND·3V3）。

## 上电检查（沿用面包板版清单）

- 万用表量 J8 空载：BAT+ 对 GND 应不通；接电池后 VM 端子（J6 V-OUT 侧）对 GND ≈ 电池电压（经 INA226）
- J9 插跳线帽 = 逻辑上电；拔掉 = 逻辑断电（拔电池才是完全断电）
- 先不接电机，I²C 扫描应出 **0x40 (INA226)** 和 **0x68 (MPU6050)**
- 低 PWM（30%）试转，方向不对就对调 AO1/AO2（或 BO1/BO2）两根电机线
- 烧录失败：拔下 microSD 模块再烧（GPIO2 是启动脚，与面包板版相同）

## 已知取舍

- microSD / INA226 / MP1584 采用杜邦线对接而非插座直插：这三个模块市面上丝印顺序五花八门，直插底板一旦做错就整板报废；标牌对接对任意版本零风险，也便于烧录时拔 SD。
- 逻辑电源开关（J9 跳线）只控制 MP1584 输入（≤0.5A）；电机主回路不串开关（小开关扛不住堵转电流），完全断电请拔电池端子。
