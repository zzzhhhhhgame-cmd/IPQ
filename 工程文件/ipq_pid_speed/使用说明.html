0概述

研究问题：开环 PWM 下，两个电机因个体差异（绕组、减速箱摩擦、地面接触）产生约 5% 的轮速差，导致小车跑偏。 本程序给每个轮子配一套独立的 PID 速度闭环，让两轮实际转速都收敛到同一目标值——差速被控制器自动吸收。

对照实验能力：按 o 可在行驶中一键切换「开环（两轮相同 PWM）↔ 闭环（PID）」，开环模式即差速对照组；效果用两个独立量评价——轮速差 d rpm（编码器）和车体转向角速度 gyrZ（陀螺仪）。

本程序与综合测试程序 ipq_robot_test 相互独立：接线不变、烧谁用谁，原测试程序原样保留。

1快速开始

  1. Arduino IDE 打开 ipq_pid_speed.ino（确认开的是这个文件而不是测试程序），开发板 ESP32 Dev Module，上传。
  2. 烧录卡在 Connecting：按住 BOOT；仍失败拔掉 microSD 模块（GPIO2）。
  3. 串口监视器 115200。上电后 保持小车静止 1 秒（程序在做陀螺零偏校准，会打印结果）。

3控制原理（左右轮各一套）

                 ┌────────────── 左轮一套 / 右轮一套 ──────────────┐
                 │                                                │
 目标转速 T ──►(e = T − rpm)──► PID ──►(＋ 前馈 ff·T)──► PWM ──► DRV8833 ──► 电机 ──► 车轮
                   ▲                                            │
                   │                                            ▼
                   └────── 实测转速 rpm ◄── 低通滤波 ◄── 编码器计数 ┘
  • 控制周期 100ms；编码器差分测速后经低通滤波（系数 0.35）抑制量化噪声；
  • 输出：u = ff·T + Kp·e + Ki·∫e·dt + Kd·(−d rpm/dt)，钳位 ±255；
  • 微分作用于测量值而非误差，目标阶跃时不会产生微分踢；
  • 积分限幅 ±120（抗饱和）；停车/刹车时积分器自动复位；
  • 前馈 ff（PWM/rpm）加快收敛，设 0 即纯 PID——可做「纯 PID vs 前馈+PID」对比实验；
  • 转向命令（a/d）= 左右目标取相反符号，两环独立工作，天然支持差速转向。

4遥测行解读

[  12.3s] PID T +45.0 | L  44.8rpm u +58  R  45.3rpm u +61 | d -0.5rpm gyrZ  -0.3 | bat 8.00*V cur 0.140A pow 1.13W
字段含义怎么看
PID / 开环当前模式按 o 切换
T目标转速（带符号）—
L / R左右轮实测转速、PID 输出 PWM闭环稳定后两轮 PWM 不同（快轮小、慢轮大）——这正是控制器在吸收电机差异
d轮速差 rpmL − rpmR核心评价指标，闭环应趋近 0
gyrZ车体转向角速度（°/s，零偏已校准）独立判据：走直线应 ≈0；与 d 互相印证
bat/cur/pow电池电压 / 电机电流 / 功率* 表示替代值（INA226 母线通道损坏，用 v 命令设的值）

5实验设计建议

实验 1 · 开环 vs 闭环（核心对比）

  1. 目标 45 rpm 起步，等转速稳定；
  2. 按 o 切到开环 → 记录 10s → 切回闭环 → 再记录 10s（可在 CSV 里清晰分段）；
  3. 对比两段的 d 和 gyrZ 的均值与波动——量化 PID 的抑制效果。

实验 2 · 阶跃响应

  1. 停稳后 z 清零 → w → 跑 5 秒 → x；
  2. CSV 中即目标从 0→45 的阶跃响应曲线：上升时间、超调、稳态误差、两轮收敛差。

实验 3 · 参数影响

  1. 每组参数重复实验 2，画在同一张图上；
  2. 建议扫描顺序：只加 kp 直到轻微振荡 → 回退 30%；加 ki 消稳态差；最后尝试小 kd；ff0 对比收敛速度。

实验 4 · 不同速度下的鲁棒性：目标 15 / 45 / 90 rpm 各跑一遍（开环差速随速度变化，闭环应都能压住）。

6调参指引

参数默认范围作用与调法
kp2.00~50响应主力。加大→差速收敛快；过大→转速振荡（遥测 rpm 抖动、电机嗡响）
ki0.150~10消除稳态差速。加大→消差更快；过大→超调、来回摆
kd00~10抑制超调。转速有量化噪声，从 0.02 小量试
ff1.30~3前馈 PWM/rpm，加速起步收敛；0 = 纯 PID 对照
起步瞬间输出 = ff×45 + kp×45 ≈ 148/255（约 58%），足以冲破静摩擦，所以闭环低速起步比开环干脆。

7SD 卡数据文件

每 100ms 追加一行到 /pidNNN.csv（自动递增不覆盖，每秒落盘），断电取卡后 Excel / Python pandas 直接读：

ms,tgt,rpmL,rpmR,pwmL,pwmR,gyrZ,busV,curA,powW
列含义
ms开机毫秒数
tgt目标转速（带符号）
rpmL / rpmR左右轮实测转速
pwmL / pwmR控制器输出（−255~255）——两列的差就是控制器为抵消电机差异付出的努力
gyrZ车体转向角速度（°/s）
busV / curA / powW电池电压 / 电机电流 / 功率（busV 为空或为 v 命令设定值时表示替代）

8注意事项

事项说明
上电静止 1 秒陀螺零偏校准在开机时进行；若开机时车在动，gyrZ 会带偏，按 RST 重来
参数掉电丢失kp/ki/kd/ff/目标转速/电池替代值均在内存中，重开机需重设
bat 带 *当前 INA226 模块母线通道损坏，用 v8.06 设定值；换新模块自动恢复实测
bat/cur 变 ----INA226 被震动震掉线，程序每 10s 自动重连；反复出现就重新插它的 4 根线
烧录失败按住 BOOT 键；拔掉 microSD 模块（GPIO2 是启动脚）
原地转向测试a/d 命令下左右轮目标相反，转速与编码器计数为一正一负，属正常
