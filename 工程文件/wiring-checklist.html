⚠ 接线前的四个关键说明

① 电池线「一分为二」怎么做到？
电池的 (+) 要同时供给 INA226 VIN+ 和 MP1584 IN+；(−) 要同时供给 DRV8833 GND 和 MP1584 IN−。物理实现二选一：
方式 A（推荐）：把两根线的铜端并排一起压进同一个螺丝端子——电池(+)和去 MP1584 的红线同压 INA226 的 VIN+ 端子；电池(−)和去 MP1584 的黑线同压 DRV8833 的 GND 端子。逻辑电流不会流过 INA226 分流电阻，测量仍然只含电机 ✅
方式 B：在电池引线上焊接 Y 形分头，热缩管/胶带绝缘。
❌ 不许把 7.4V 动力电放上面包板轨道；❌ 电机电流路径（线 1/2/3/27–30）不经过面包板。
② microSD 模块的 VCC 电压（线 15）先看板子再接：
板上有 AMS1117 稳压器芯片 + 电平转换芯片 → VCC 接 5V（从 MP1584 OUT+ 引一根，不占红轨）；
板上没有稳压器、直通 3.3V → VCC 接面包板红轨 (3.3V)。
接错电压轻则不读卡，重则烧卡。
③ 面包板两轨定义：
红轨 ⊕ = ESP32 输出的 3.3V（源头是 ESP32 的 3V3 引脚，即线 8）
蓝轨 ⊖ = GND 汇流（源头是 ESP32 的 GND 引脚，即线 9）
⚠ 先用万用表确认你的面包板轨道中段没有断开（红轨首尾孔量通断），断了就拿线桥接。
④ GPIO 12 与 GPIO 0 禁用（启动 strapping 脚）：
GPIO 12（丝印 D12）在开机瞬间若是高电平，ESP32 会把 flash 电压切到 1.8V → 反复重启、进不了系统。CS 平时就是高电平，接 12 必定无法开机；SD 模块其它线（带上拉）同样会踩雷。GPIO 0 则影响烧录模式，也不要占用。
→ 因此 CS 从 GPIO 13 改到 GPIO 27（13 本身安全，但它的插孔紧挨着 D12，容易数错一格误插）。

🎨 线色约定（强烈建议遵守）

颜色统一，排查问题时能省一半时间。没条件全遵守时，至少保证：红=正、黑=地。
红 = 电池+ / 3.3V
黑 = GND
黄 = 编码器 A 相
绿 = 编码器 B 相
蓝 = I²C SDA / 左电机
白 = I²C SCL / 右电机
紫 = PWM 调速
橙 = 方向控制

✅ 全部接完后的上电快检

  • 万用表蜂鸣档：电池(+) ↔ 各模块 VCC 不应短路到 GND（红轨 ↔ 蓝轨应不通）
  • 电池电压 ≤ 8.4V（2S 满电）；MP1584 OUT+ 对 GND ≈ 5V（定压版只验证不调）
  • DRV8833：STBY 已接红轨、VM 上量到电池电压（经 INA226）
  • 先拔电机线，只上逻辑电：ESP32 跑 I²C 扫描，应出现 0x40（INA226）和 0x68（MPU6050）
  • I²C 通了再接电机：PWM 30% 低速试转，方向不对就对调 AO1/AO2（或 BO1/BO2）
  • 烧录程序失败时：拔掉 microSD 模块再烧（GPIO 2 是启动脚，SD 卡会干扰进烧录模式）
  • 任何线都不得接 GPIO 12 / GPIO 0（启动脚，接高会无法开机或无法烧录，见说明④）
