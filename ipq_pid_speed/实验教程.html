速通五步速通版（赶时间看这里）

  1. IDE 打开 ipq_pid_speed.ino，选 ESP32 Dev Module，上传；
  2. 上电后车静止 1 秒（陀螺校准）；
  3. 关掉 IDE 串口监视器，命令行进入 D:\IPQ\ipq_pid_speed 运行 py serial_logger.py，选 ESP32 的 COM 口；
  4. 依次发送：v8.06 → e（开 CSV）→ t（关刷屏）→ 3 → w，开跑；
  5. 做完 Ctrl+C，目录里拿 pid_log_时间戳.csv。

①上传固件（约 1 分钟）

  1. Arduino IDE 文件 → 打开，选择 D:\IPQ\ipq_pid_speed\ipq_pid_speed.ino——确认标题栏是这个文件，别开成测试程序 ipq_robot_test；
  2. 工具 → 开发板 → ESP32 Dev Module（其它选项默认）；
  3. USB 连接 ESP32，工具 → 端口 选新出现的 COM 口；
  4. 点右上角 上传（→ 按钮），等编译写出完成、板子自动复位。
卡在 Connecting........：按住板上 BOOT 键不放再点上传，开始写出时松开；仍失败 → 拔掉 microSD 模块再烧（GPIO2 是启动脚），烧完插回。

②开机自检（约 10 秒）

暂时还需要看一眼串口：IDE 打开串口监视器（115200），按一下板上 RST 复位，车保持静止，应看到：

===== IPQ · 双电机差速 PID 抑制 =====
I2C 扫描: 0x40 0x6B
  [INA诊断] CFG回读=0x4587 OK
  IMU: LSM6 系 (0x6B) 初始化成功
  IMU 陀螺零偏校准中（保持静止）…完成（Z 轴 -6.3 dps）
SD 卡初始化失败（不影响其它功能…）      ← 没插卡，正常，忽略
上电默认：PID 闭环、目标 45rpm、kp2.0 ki0.15 kd0 ff1.3
  • 0x40（INA226）和 IMU 行正常即可；「SD 卡初始化失败」是没插卡的预期提示；
  • 陀螺校准必须在静止时进行——如果开机时车在动，按 RST 重来一次；
  • 看完后关闭串口监视器（右上角 × 或断开按钮），进入下一步。

③连接电脑记录器（约 1 分钟）

  1. Win+R 输入 cmd 回车，打开命令行；
  2. 执行： 
    cd /d D:\IPQ\ipq_pid_speed
py serial_logger.py
  3. 脚本列出串口，形如 [0] COM3 Silicon Labs CP210x 或 CH340——输入 ESP32 对应的序号回车；
  4. 看到遥测滚动即连接成功。此窗口既是记录器也是命令终端：直接输入命令回车即可发送。
提示"拒绝访问/Access Denied"：Arduino IDE 的串口监视器还开着，先关掉再运行脚本。

开始记录前的三连命令

v8.06        ← 设电池电压（按万用表实际读数，功率更准）
e            ← 开启 CSV 数据输出（每 100ms 一行）
t            ← 关闭人读遥测，只留数据行

之后窗口里滚动的内容就是纯数据行，例如：

9234,45.0,44.6,45.1,58,61,-0.4,8.06,0.142,1.15

④做实验（核心环节）

安全提醒：第一次建议架空轮子验证行为，再下地。任何异常立刻发 x 刹车。原地转向（a/d）轮子会一正一反，正常现象。

实验 A · 开环 vs 闭环对比（研究核心，先做这个）

  1. 发 3（目标 45 rpm）；
  2. 发 w 起步，等 3~5 秒转速稳定；
  3. 发 o 切到开环，保持 10 秒（对照组，有差速、车会跑偏）；
  4. 再发 o 切回闭环，再保持 10 秒；
  5. 发 x 刹车。可在 txt 记录里看到这些切换点，CSV 数据自动分好段。

分析指标：两段的 rpmL−rpmR（差速）和 gyrZ（转向角速度）的均值与波动——闭环应显著趋近 0。

实验 B · 阶跃响应（调参的基础测量）

  1. 停稳后发 z（编码器清零）；
  2. 发 w，跑 5 秒；
  3. 发 x 结束。CSV 里就是 0→45rpm 的完整阶跃响应曲线；
  4. 同组参数建议重复 3 次取平均。

实验 C · 参数扫描（论文素材主力）

每组参数改完后重复实验 B（或再加一轮 A），推荐顺序：

轮次改动观察什么
1kp1.0 → kp2.0 → kp4.0 → kp6.0响应变快；kp 过大时转速振荡（数据毛刺、电机嗡响），记下临界值后回退 30%
2用回退后的 kp，改 ki0 → ki0.15 → ki0.3稳态差速消除速度；ki 过大有超调/来回摆
3kd0.02（可选）超调是否减小
4ff0 vs ff1.3纯 PID 与前馈+PID 的收敛速度对比

实验 D · 不同速度的鲁棒性

用最终参数，分别在 r15 / r45 / r90 下重复实验 A——开环差速随速度变化，闭环应都能压住。

⑤结束记录与数据文件

  1. 先 x 刹车，再按 Ctrl+C 结束脚本；
  2. 目录下生成两个文件：
    • pid_log_时间戳.csv —— 纯数据行（第一行是列名），分析用这个；
    • pid_log_时间戳.txt —— 全部串口输出，含你发过的命令，用来对分段。
  3. 按实验记录表把文件重命名或登记，防止混淆；
  4. 数据可以直接：Excel 打开画图；或 pandas：df = pd.read_csv("pid_log_xxx.csv")。

CSV 列含义

列含义
ms开机毫秒数（时间轴）
tgt目标转速（带符号）
rpmL / rpmR左右轮实测转速
pwmL / pwmR控制器输出——两列的差 = 控制器为抵消电机差异付出的努力
gyrZ车体转向角速度（°/s），直线应 ≈0
busV / curA / powW电池电压 / 电机电流 / 功率（busV 为 v 命令设定值时是替代值）

⑥常见问题

现象处理
脚本打不开端口（拒绝访问）IDE 串口监视器没关；或换了个 USB 口（端口序号变了）
列表里没有串口重插 USB；设备管理器确认 CH340/CP210x 驱动正常
窗口只有遥测没有数据行忘了发 e（开启 CSV 输出的命令）
csv 文件是空的同上——e 开启后才有 CSV 行
直线时 gyrZ 一直偏开机陀螺校准时车在动 → 按 RST 静止重开，并重连记录器
bat/cur 变 ----INA226 被震动震松，程序 10 秒后自动重连；反复出现就重插它的 4 根线
转速遥测个位数跳动100ms 窗口的量化噪声（分辨率约 1.8 rpm），正常
换了参数没效果确认命令格式：kp3.0（无空格）；改完看回显确认
重新上电后参数变回默认设计如此（掉电丢失），按记录表重设
